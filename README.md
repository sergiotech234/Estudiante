# Ejercicio 4: Estudiante

## 📌 Descripción

Este ejercicio consiste en desarrollar una clase llamada `Estudiante` utilizando los conceptos de **Programación Orientada a Objetos (POO)** en Java.

La clase representa a un estudiante y almacena sus datos personales y académicos. Además, incorpora una variable estática para llevar el recuento del número total de estudiantes creados correctamente.

## ⚙️ Validaciones

Se establecen las siguientes condiciones:

- La edad no puede ser negativa.
- La nota debe estar comprendida entre `0` y `10`, ambos incluidos.
- Se acepta una nota de `0`.
- Se acepta una nota de `10`.
- No se aceptan notas negativas ni superiores a `10`.

Si se intenta crear un estudiante con datos incorrectos, el objeto no debe crearse correctamente y el contador no debe incrementarse.

## ✅ Conclusión

Con este ejercicio se refuerzan los conocimientos de programación orientada a objetos en Java, especialmente el uso de atributos privados y métodos estáticos.

También se aprende a realizar validaciones para garantizar que los datos sean correctos y a utilizar un contador compartido para conocer el número de objetos creados correctamente.
